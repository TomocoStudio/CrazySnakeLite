## What Was Changed

### Border System Simplification

**Before V4.2 (7 states):**
1. Death flash (red) ❌ REMOVED
2. Phone ring (gold) ❌ REMOVED
3. Phone pickup (green) ❌ REMOVED
4. Combo mode (dynamic colors) ❌ REMOVED
5. Reverse controls (orange) ❌ REMOVED
6. Invincibility (yellow) ✅ KEPT
7. Default (purple) → Changed to black

**After V4.2 (3 states):**
1. Wall-phase (purple) - Walls safe to cross
2. Invincibility (yellow blinking) - Protected state
3. Default (black) - Walls dangerous

### Design Principle Change

**Old:** Border color = game state/mode/event (7 different meanings)

**New:** Border color = danger level (3 semantic meanings)

- ⚫ Black = Danger (walls kill)
- 🟣 Purple = Safe walls (wall-phase active)
- 🟡 Yellow = Protected (invincibility active)

### Universal Application

V4.2 rules apply to **ALL game modes:**
- Normal gameplay ✅
- Combo mode ✅
- Phone calls active ✅
- All effects ✅

No more mode-specific border colors.
