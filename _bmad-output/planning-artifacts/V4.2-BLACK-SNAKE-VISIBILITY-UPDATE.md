# V4.2 Visual Enhancement — Black Snake Visibility Update

**Date:** 2026-02-17
**Status:** Implemented
**Requested by:** Tomoco
**Implemented by:** Amelia (Dev Agent)
**UX Validated by:** Sally's Five-Question Filter (documented in ux-design-retro-graphic-upgrade.md)

---

## Summary

Enhanced snake rendering to improve visibility of black snake against the dark (`#1a1a1a`) background introduced in V4.1 Neon Noir update.

**Solution:** Adaptive glow and border system — white when snake is black, colored otherwise.

---

## What Changed

### Visual Changes

**Before (V4.1):**
- Black snake: Black fill + black glow (blur 8) + black border → poor visibility on dark background

**After (V4.2):**
- Black snake: Black fill + **white glow (blur 6)** + **white border** → high visibility
- All other colors: Colored fill + colored glow (blur 6) + black border → unchanged behavior
- Glow blur reduced: 8px → 6px for all snakes (subtler, crisper effect)

### Code Changes

**File:** `js/render.js`
**Functions Modified:** `renderSnake()` (both striped and normal rendering paths)
**Lines Changed:** 4 lines (2 locations, glow + border logic)

**Pattern:**
```javascript
// Adaptive glow color
const glowColor = snakeColor === '#000000' ? '#FFFFFF' : snakeColor;

// Adaptive border color
ctx.strokeStyle = snakeColor === '#000000' ? '#FFFFFF' : '#000000';
```

---

## When This Applies

The white glow + white border activate in these scenarios:

1. **Game start** (before eating any food) → snake is black
2. **Wall phase effect active** → snake turns/stays black
3. **Invincibility strobe** (black phase) → alternates yellow/black, white glow on black phase
4. **Combo mode** (striped snake) → black segments get white glow, colored segments keep colored glow

## Design Philosophy

This enhancement exemplifies the V4 "Neon Noir" aesthetic:
- **Dark void background** (constant `#1a1a1a`)
- **Maximum contrast neon glow** (white on black)
- **80s arcade CRT phosphor effect** (glowing objects in absolute darkness)
- **Cognitive clarity** (player instantly locates their character)

The white-glowing black snake against the dark void creates a striking "neon ghost" visual that reinforces the retro arcade immersion while serving the functional goal of visibility.
